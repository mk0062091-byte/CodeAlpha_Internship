# Megha Kashyap Portfolio

This project is a personal portfolio website built using HTML, CSS, and JavaScript. It showcases my skills, projects, resume, and interactive demo sections.

## Features

- Modern responsive portfolio layout
- About section with personal introduction
- Skills section categorized by type
- Projects section with project cards
- Interactive demo: Image Gallery
- Interactive demo: Calculator
- THDC Online Attendance Register System demo
- Resume download section
- Contact form UI

## Project Structure

- `index.html` — main portfolio page
- `style.css` — all styling and responsive design
- `script.js` — interaction logic for demos and UI behavior
- `resume.pdf` — downloadable resume
- `resume.txt` — text version of the resume

## How to Run

### Option 1: Open directly
Open `index.html` in a browser.

### Option 2: Run a local server
From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```
